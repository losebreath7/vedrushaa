# Правила проекта Vedrushaa

## Остановка прокрутки на каждом экране

Обязательное условие для каждого существующего и нового смыслового экрана или блока лендинга: у него есть воспринимаемая точка остановки. Когда композиция целиком заняла окно, посетитель может спокойно прочитать текст или воспользоваться элементами управления. Остаточная инерция того же жеста не должна сразу уносить блок дальше. Продолжение — следующим самостоятельным движением колеса, трекпада или свайпом.

Для блока выше области просмотра точку остановки привязывать к содержательному кадру и сохранять возможность прокрутить всё содержимое. Для многошаговой сцены согласовывать остановки с её сюжетом. Сохранять плавный ход между остановками, возможность вернуться назад, переходы по меню и доступ с клавиатуры.

Перед публикацией проверять поведение в реальном браузере длинным жестом: экран доходит до точки остановки, остаётся читаемым после затухания инерции, а следующий жест ведёт дальше. Отдельно проверять обратное направление. В отчёте указывать фактически проверенные устройства и способы ввода.
